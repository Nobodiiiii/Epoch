# 方块兼容实现记录（2026-10-05）

这是 `SEAMLESS_BLOCK_COMPATIBILITY_PLAN.md` 的阶段实现记录，不代表原方案全部完成。

## 已接入的路径

五版本的完整快照导入与流式区块导入均接入 `BlockPayloads`；三个现代版本接入 `BlockSemantics` 的历史状态规范化，两种旧版使用同一套语义反向匹配。
1.7.10、1.12.2 的完整/区块导出均接入 `LegacyContext` / `BlockContext`，使用已加载源世界的邻居信息，查询本身不会生成邻块。

`SnbtFields` 编辑 compound 时保留未修改值的原始 SNBT 文本，包含长整数、各类数组与嵌套数据。没有通过 JSON 浮点数中转 NBT。
`BlockPreservation` 是导入期间的临时原始数据引用，不写入磁盘协议；目标状态或 NBT 验证失败时，未知方块保留转换前的状态和负载，避免保留半转换的数据。

## 本次实现范围

| 家族 | 已实现 | 仍有边界 |
|---|---|---|
| 泥土 | 1.7 dirt:1 → coarse_dirt，反向 meta=1；恢复已有原始 legacy payload | 不放开无效 metadata |
| 名称 | 六种 bark/wood、mob_spawner/spawner、portal/nether_portal；旧版空/水炼药锅落地 | wood 非 y 轴未假定可逆；真正新增方块仍保留 |
| 树叶 | 源邻域 BFS 重建距离，decayable/persistent 转换；现代干叶反向落地；杜鹃两种干叶到 1.18.2 | 缺关键邻域时保留；含水不丢弃；不同版本腐烂机制未改写 |
| 楼梯、门、植物 | 重建楼梯转角；联合门两半字段；双格植物从下半部识别种类；旧版 metadata 反向匹配 | 尚无完整跨区块依赖事务和真实世界结构矩阵 |
| 连接块与箱子 | 栅栏/板/铁栏杆连接、积雪、栅栏门、双箱类型的源邻域重建；目标旧版按可推导字段匹配 | 模组连接语义与复杂形状未完整验证 |
| 墙 | 上方为空气或正常完整方块时重建 none/low/tall 与柱子；现代墙到旧版匹配 | 上方复杂碰撞形状、连续墙柱等保持待上下文状态，未用近似值冒充等价 |
| 花盆 | 修正旧表把所有花盆写为仙人掌的问题；常见旧植物 Item/Data 与 potted_* 双向转换 | 新植物和未知附加字段不消费 |
| 床/旗帜 | 床色、旗帜底色及图案颜色在状态/NBT 间搬运 | 1.7 无彩色床/旗帜；不替换为近似颜色 |
| 头颅 | 基础种类、放置面和旋转双向转换 | NoDrop metadata、1.7 不存在的龙头、复杂玩家资料依赖原生负载验证，未做通用资料迁移 |
| 音符盒 | 源原生材质确定旧版乐器，音高/供电从 NBT 搬入状态；共同旧音色反向恢复 tile | 新音色仍保留；旧存量负载若缺乐器上下文不猜测 |
| 告示牌 | 普通文本、旧四行与 1.20 front/back 数据结构转换；原生序列化格式核对 | 降级不吞掉非空背面、封蜡、发光/颜色/过滤差异或旧版不支持的文本样式 |
| 刷怪笼 | 白名单常见生物的基础 EntityId/SpawnData/SpawnPotentials 结构双向转换；保留延迟和权重 | 丰富实体 NBT、custom_spawn_rules 等没有通用转换器，继续保留 |
| 导入失败 | 完整原始状态/NBT 回退，沿用原生工厂、类型、序列化保留检查 | 不把转换失败变成空气或直接删除未知字段 |

缺上下文的源状态带 `EpochLegacyVersion="epoch-context-v1"` 与 `EpochContextRequired`。现有旧读取器也会拒绝这种版本标记，避免把未完成状态误当正常方块。
音符盒缺少下方材质、或连接计算遇到未知占位块而无法获得真实形状时，同样保持待上下文状态，不使用竖琴或占位块的实体碰撞形状冒充源语义。
新读取器可在完整快照提供必要邻居时重新尝试；涉及 native 碰撞形状或外部区块的依赖尚未实现自动补齐。
