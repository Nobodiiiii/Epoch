# 未知方块的来源外观

未知方块及其对应的方块物品使用同一份来源模型。模型表面显示滚动的青色扫描条线，穿插短暂闪烁。条线在共享动态材质中以 12 Hz 更新，每个模型面仅提交原始四个顶点；同一材质无论被多少方块/物品使用，每个动画帧只更新一次。动画使用渲染时间，暂停或交接冻结不会使条线停止。放置、挖掘掉落、中键复制、保存和继续跨版本传递均保留来源实例标识。碰撞和交互仍采用占位方块逻辑。

## 资源来源

- 新快照保存 `sourceInstance`，每个已有占位位置通过 `appearanceSources` 保留更早的来源；区块拆分同步保留。占位实体和 `BlockEntityTag` 保存 `SourceInstance`。
- 来源客户端在渲染线程读取原生 baked model、状态朝向、贴图 UV 和方块染色。PNG 取自该客户端当前启用的资源管理器。文件写入在后台执行，缓存位于 `.minecraft/epoch/appearances/<instance>/`；材质采用内容哈希，模型采用原始状态哈希。
- 没有缓存时，目标后台线程按 catalog 中的精确实例查找资源。离线模式按启用资源包的逆序、模组 JAR、客户端 JAR 查找，解析普通 JSON 模型的父级、材质别名、variants、multipart、元素旋转和面 UV。不会加载来源模组代码。
- 同时向来源实例的请求目录提交缺失状态；运行中的来源客户端会处理原生模型导出请求。原生导出到达后自动替换先显示的离线近似模型。文件不存在、数据不支持或来源不明时显示带同样故障条线的占位模型，不影响原始数据保存。
- 旧占位数据没有实例标识，只能在 catalog 中该版本恰好对应一个实例时尝试反查；多个同版本实例时不猜测。更早版本中已丢失的来源版本信息无法可靠补回。
- 目标资源重载会释放已注册动态材质并清空内存缓存。来源资源包发生变化后，来源重新导出，目标重载资源后重新读取。缓存是本机可再生显示数据，不属于原始方块 NBT。

## 支持边界

1.12、1.16、1.18、1.20 可以导出普通 baked model。依赖方块实体渲染器、动态 ModelData 或专用模组加载器的模型不保证完整；没有可导出的面时保留占位显示。来源环境相关染色使用来源玩家附近的上下文，而非每一格原始群系；原生随机模型使用固定种子，缓存按方块状态复用。

1.7.10 没有 baked model 系统，目前原生导出仅支持普通 render type 0 的六面材质立方体；特殊渲染类型回退占位。离线 JSON 模型可以在所有目标版本显示，包括旧版客户端显示新版台阶。

离线解析不执行自定义模型加载器；旋转且开启 UV lock 的模型需要原生导出。加权模型选择第一项，群系染色不能离线重现。动态原始材质使用常见纵向动画的首帧；故障条线独立动态播放。此功能针对未知方块及其方块物品，不改变 `unavailable_item` 的物品兼容信封。

## 验证

- 五个适配器的离线 Gradle `build`，包含既有原生环境、物品兼容和旧版生命周期检查。
- `tests/test_shared.ps1` 增加来源实例往返、空来源不冒充中转实例、区块拆分、路径与模型校验、缓存隔离、动态条线、离线父模型/别名/资源包覆盖测试。
- 使用本机 1.20.1 实例实际资源解析樱花木板和下半樱花台阶：均为六面，模型高度分别为 1 和 0.5。
- 未进行游戏画面视觉验收或大规模占位地形帧率测量。渲染器剔除被相邻不透明完整方块遮挡的边界面；特殊模型和大面积透明占位地形仍需实际客户端验证。

## 大片树叶的性能修复

上一版每面分成 24 条、每条提交四个顶点，并逐条求扫描线颜色；每个完整方块需提交 576 个顶点。所有材质还都使用半透明渲染路径。已改为原始四顶点面和共享材质动画，完整方块回到 24 个顶点。只有含部分透明度的材质使用半透明混合；树叶常见的 0/255 透明度使用 cutout，扫描线不会填满叶片孔洞。这里的 24 倍是顶点提交数量变化，不是实测帧率提升倍数。

现代适配器复用每种材质的 RenderType；1.7/1.12 将同一模型中连续使用相同材质的面合并到同一次 Tessellator 提交，普通六面树叶由六次提交降为一次。旧版也移除了逐方块读取 GL 纹理绑定的同步查询。面边界计算缓存一次，现代版本的邻居查询复用可变坐标，模型缓存命中不再构造路径、校验正则或拼接哈希键。

`AppearancePerformanceTest` 模拟 10,000 片树叶的六面材质引用，在 24 个动画帧中共 1,440,000 次引用只触发 24 次像素更新；同时验证透明度不变、ARGB/ABGR 通道转换和缓存热路径分配量。此测试不运行 OpenGL，不替代用户场景的实际 FPS 测量。
